# Guía de análisis de ventas

## Objetivo

Describir los indicadores utilizados para analizar
el comportamiento comercial de PharmaSphere.

## Indicadores principales

### Ventas por día

Permite observar la evolución de las operaciones
registradas durante un periodo determinado.

### Productos más vendidos

Identifica los productos con mayor cantidad de
unidades comercializadas.

### Rendimiento por sucursal

Permite comparar los resultados de las diferentes
sucursales de la farmacia.

### Historial de ventas

El historial permite analizar:

- Cantidad de operaciones.
- Ingresos registrados.
- Productos comercializados.
- Métodos de pago.
- Distribución temporal de las ventas.

## Estados de las ventas

El sistema utiliza los siguientes estados:

- pendiente: operación pendiente de completar.
- pagada: operación pagada.
- retirada: pedido entregado o retirado.
- cancelada: operación cancelada.

Los reportes deben considerar los estados según
las reglas de negocio implementadas.

## Uso de datos demo

Los datos de demostración permiten observar tendencias
históricas y comprobar el funcionamiento de las gráficas,
los reportes y las recomendaciones del Pharmacy Copilot.

Los datos no representan operaciones comerciales reales.
