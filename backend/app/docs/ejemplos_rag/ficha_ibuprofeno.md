# Ficha informativa: Ibuprofeno

Ficha de ejemplo con fines informativos. No sustituye la indicación de un médico o farmacéutico.

## Para qué se usa

Antiinflamatorio no esteroideo (AINE). Se usa para dolor, inflamación y fiebre.

## Advertencias

- Tomarlo con alimentos para reducir la irritación del estómago.
- No usar con úlcera gástrica, enfermedad renal grave ni alergia a los AINE.
- No usar en el tercer trimestre del embarazo.
- Consultar al médico si se toman anticoagulantes, otros antiinflamatorios o medicamentos para la presión.
- No usar por más tiempo del indicado sin consultar.

## Venta

Según la presentación y concentración, puede requerir receta. Verificar el campo "requiere receta" del producto.
